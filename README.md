# t3code (mesh build)

Personal Android build of [T3 Code](https://github.com/pingdotgg/t3code) with
Android KeyChain client certificates (mTLS), for use with
[t3-mesh](https://github.com/zekihan/t3-mesh). It is installed only on the
owner's own devices and is not supported for anyone else.

This repository is a standalone copy of `pingdotgg/t3code`, not a GitHub fork.

| Branch | Holds |
|---|---|
| `main` | The build's workflows only |
| `candidate` | Each rebased stack, before it is released |
| `mesh` | The stack of the newest published release, on top of an upstream nightly tag |

The plan is [docs/android-fork.md](https://github.com/zekihan/t3-mesh/blob/main/docs/android-fork.md)
in t3-mesh. Upstream's license applies to its code (MIT).
